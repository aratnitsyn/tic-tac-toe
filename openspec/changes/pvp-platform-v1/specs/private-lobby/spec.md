## Purpose

Позволяет двум зарегистрированным игрокам организовать приватную партию через приглашение по коду.

## ADDED Requirements

### Requirement: Create and join lobby
Система SHALL позволять свободному авторизованному игроку создать приватное лобби и получить код приглашения. Другой свободный авторизованный игрок SHALL иметь возможность присоединиться по этому коду. Вместимость лобби — два разных игрока.

#### Scenario: Friend joins
- **WHEN** второй игрок вводит действующий код доступного лобби
- **THEN** он присоединяется, и для пары начинается проверка готовности

#### Scenario: Invalid or full lobby
- **WHEN** код не соответствует доступному лобби либо в нём уже два игрока
- **THEN** вход отклоняется без изменения участия запрашивающего игрока

#### Scenario: Concurrent joins
- **WHEN** несколько игроков одновременно занимают последнее место
- **THEN** присоединяется не более одного из них

### Requirement: Lobby-origin cancellation
При отмене подготовки система SHALL сохранять лобби для подтвердившего готовность игрока либо для оставшегося подключённого игрока при отмене предстартового отсчёта. Другой игрок возвращается в меню. При формировании новой пары прежнее подтверждение не переносится.

#### Scenario: Friend does not accept
- **WHEN** истекли 10 секунд готовности и только один игрок подтвердил участие
- **THEN** подтвердивший остаётся в лобби и может пригласить другого, не подтвердивший возвращается в меню

#### Scenario: Disconnect during countdown
- **WHEN** один игрок отключается во время предстартового отсчёта
- **THEN** подключённый возвращается в лобби, отключившийся переводится в меню

### Requirement: Leave waiting lobby
Система SHALL разрешать выход из ожидающего лобби с возвратом в MENU и освобождением места. Выход из ожидающего лобби не применяется как освобождение участия уже сформированного матча.

#### Scenario: Leave before friend joins
- **WHEN** единственный участник выходит из ожидающего лобби
- **THEN** он переводится в MENU и больше не занимает место в комнате
